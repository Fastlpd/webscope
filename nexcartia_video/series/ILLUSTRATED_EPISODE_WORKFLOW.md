# Illustrated Episode Production Workflow

Every episode is a connected illustrated cinematic chapter. Work in versioned folders; never overwrite an approved version.

## Required package
- `brief.md`: purpose, dramatic question, emotional promise, timeline and runtime target.
- `script.md`: complete screenplay with scene numbers and sluglines.
- `continuity.md`: character knowledge, relationships, in-world time, props, wardrobe, locations and Milo's age.
- `storyboard.md`: shot-by-shot visual direction.
- `illustration_prompts.md`: prompts for each scene image, each tied to approved character references.
- `illustrations/`: separate image file for every major scene/story beat.
- `scene_image_index.md`: maps each image to script scene and shot.
- `approval.md`: creator decisions and rejected/revision notes.

## Production gates
1. Approve the story bible and episode brief.
2. Approve permanent character portraits and family resemblance.
3. Approve the complete screenplay.
4. Approve storyboard and illustration prompts.
5. Generate scene illustrations in a consistent style, using approved references.
6. Review identity, continuity and composition; reject mismatched faces.
7. Only then consider the episode ready for video generation.

## Illustration rule
Illustrations are individual scene assets, not a single cover poster. A scene image must depict the actual scene's action and cast. Use the same character reference IDs throughout. If a tool cannot maintain face identity, use smaller batches and manual review. Do not silently substitute a different face.

## Versioning
Use `EP-001/v01/`, `v02/` etc. Keep earlier drafts. A creator-approved version is marked in `approval.md`; new edits create a new version rather than rewriting approved assets.
